---
name: get-started
description: Connect Leadbase, verify workspace access without paid research, and help the user choose a first company, people or web research task.
---

Use the installed Leadbase MCP connection. Never ask for API keys or passwords in chat. If disconnected, use the host's connection flow; do not invent success or edit unrelated client settings.

Verify access using open_workspace or sheets_list. This is read-only and does not authorize paid work. Explain, in the user's language, that Leadbase can find companies and professional contacts, research existing rows, or collect products and public posts in an editable sheet. Offer at most three concrete examples relevant to their stated work.

If the user has already requested research, skip the introduction and execute that scope. Otherwise ask which result they need. Account connection or available credits alone is not permission to start research. Do not send outreach, buy products, purchase credits, or promise complete coverage.

Use the real MCP app to display sheets when the host supports it. The Leadbase sidebar app opens the accessible sheet library; its sheet editor supports live updates, search, filters and editing according to the account's permissions. Text-only clients receive structured results and a Leadbase link instead. Do not claim a UI rendered merely because a tool returned successfully.
